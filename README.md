# REDCORE - 3D Game Website

A vibrant and interactive 3D website for instant play games. Features 5 colorful game boxes with embedded games and an About Us section.

## Features

- **3D Animated Design**: Colorful rotating boxes with hover effects and pulsing animations.
- **Embedded Games**: First game embedded directly in the website.
- **About Us Section**: Inspiring content about REDCORE's mission.
- **Responsive**: Works on desktop and mobile devices.
- **Interactive Boxes**: Enhanced interactivity with multiple animations.

## Setup

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/redcore-games.git
   ```

2. Open `index.html` in your browser to view the website.

## Technologies Used

- HTML5
- CSS3 (with 3D transforms and animations)
- JavaScript
